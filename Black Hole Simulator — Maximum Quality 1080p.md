Создай максимально красивую и детализированную интерактивную 3D-симуляцию чёрной дыры.

Моё железо:

- GPU: NVIDIA RTX 3050 8 GB
- CPU: Intel Core i5-12400F
- RAM: 16 GB
- монитор: 1920×1080, 200 Hz

## ГЛАВНАЯ ЦЕЛЬ

Приоритет №1 — МАКСИМАЛЬНОЕ ВИЗУАЛЬНОЕ КАЧЕСТВО.

Приоритет №2 — плавность.

Рендерить строго в native 1920×1080.

НЕ использовать динамическое снижение разрешения.

НЕ использовать внутренний рендер 720p/900p с последующим upscale.

Качество изображения должно соответствовать максимально возможному уровню для RTX 3050 8 GB.

Целевой FPS:

- желательно 100–120+ FPS;
- допустимо 80–100 FPS;
- абсолютный минимум — стабильные 60 FPS.

НЕ ограничивай приложение искусственно до 60 FPS.

Если железо способно выдавать больше 60 FPS при выбранном качестве — используй эту производительность.

Используй requestAnimationFrame и VSync браузера.

# 1. ЧЁРНАЯ ДЫРА

Создай визуально максимально реалистичную чёрную дыру.

Должны присутствовать:

- горизонт событий;
- тень чёрной дыры;
- photon ring;
- гравитационное линзирование;
- искривление траектории света;
- визуальное искривление звёздного поля;
- аккреционный диск;
- внутренняя горячая область;
- внешняя холодная область;
- постепенное изменение температуры;
- вращение материи вокруг чёрной дыры.

Не делать обычный круг с glow вокруг него.

Чёрная дыра должна выглядеть как объёмный объект в искривлённом пространстве-времени.

---

# 2. ГРАВИТАЦИОННОЕ ЛИНЗИРОВАНИЕ

Это один из самых важных компонентов.

Используй GPU ray marching / ray tracing approximation.

Луч каждого пикселя должен изменять направление в зависимости от расстояния до чёрной дыры.

Реализуй:

- gravitational bending;
- photon sphere;
- multiple bending;
- distortion background;
- Einstein-ring-like effects;
- сильное линзирование возле горизонта событий.

Качество линзирования должно быть максимально высоким.

Используй adaptive ray marching:

- больше шагов возле чёрной дыры;
- меньше шагов далеко от неё;
- early exit;
- adaptive step size.

Не выполняй 200 тяжёлых операций для каждого луча, если они уже не нужны.

---

# 3. АККРЕЦИОННЫЙ ДИСК

Сделай диск максимально детализированным.

Не используй простую плоскую текстуру.

Используй процедурную генерацию.

Диск должен иметь:

- несколько масштабов шума;
- турбулентность;
- горячие области;
- неоднородную плотность;
- движение вещества;
- спиральную структуру;
- внутренние и внешние зоны;
- температурный градиент.

Цвет должен вычисляться из температуры.

Сделай переход:

горячая внутренняя часть
→ бело-жёлтая
→ жёлтая
→ оранжевая
→ красноватая
→ тёмная внешняя часть.

Не делай цвета чрезмерно насыщенными.

---

# 4. РЕЛЯТИВИСТСКИЕ ЭФФЕКТЫ

Реализуй визуально корректные эффекты:

- gravitational redshift;
- gravitational blueshift;
- relativistic Doppler effect;
- Doppler beaming;
- различие яркости приближающейся и удаляющейся стороны диска.

Одна сторона диска должна выглядеть заметно ярче из-за релятивистских эффектов.

---

# 5. ЗВЁЗДНОЕ ПОЛЕ

Создай настоящее 3D-звёздное пространство.

Не используй просто 2D background image.

Минимум:

30 000–100 000 визуальных звёзд.

Но НЕ обновляй десятки тысяч объектов через JavaScript каждый кадр.

Используй GPU/procedural generation.

Звёзды должны также проходить через gravitational lensing.

При вращении камеры звёздное поле должно ощущаться объёмным.

# 7. СУПЕРКАЧЕСТВЕННЫЙ РЕНДЕР

Native resolution:

1920×1080.

Используй максимально качественный anti-aliasing, доступный в WebGL 2.0.

Используй temporal accumulation / supersampling, если это возможно без существенной потери FPS.

Если полноценный supersampling слишком дорогой, используй более дешёвый вариант:

- FXAA/SMAA-подобный подход;
- temporal smoothing;
- jittered sampling.

Цель — убрать:

- jagged edges;
- ступеньки;
- шум;
- мерцание;
- pixel crawling.

---

# 8. ПОСТОБРАБОТКА

Добавь качественную кинематографическую обработку:

- HDR-like tone mapping;
- bloom;
- glare;
- subtle lens glow;
- vignette;
- лёгкую chromatic aberration;
- filmic response;
- мягкое свечение горячего газа.

Но эффекты должны быть умеренными.

Главная цель — физически убедительная картинка, а не большое количество эффектов.

Bloom реализовать оптимизированно через downsampled framebuffer, а не несколько дорогих полноразмерных проходов.

# 10. АВТОМАТИЧЕСКАЯ ОПТИМИЗАЦИЯ

Очень важно:

НЕ снижать разрешение.

Если FPS падает:

1. уменьшить raymarch steps;
2. уменьшить количество второстепенных вычислений;
3. уменьшить качество bloom;
4. уменьшить secondary sampling;
5. уменьшить количество звёзд;
6. только после этого снижать другие второстепенные эффекты.

1920×1080 сохранять всегда.

Используй hysteresis.

Например:

если FPS < 58 длительное время → немного снизить качество;

если FPS > 100 длительное время → постепенно вернуть качество.

Не менять качество каждый кадр.
